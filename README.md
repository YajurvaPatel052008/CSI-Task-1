# CSI AITR Event Management Dashboard

## Live Demo

https://yajurvapatel052008.github.io/CSI-Task-1/

## About the Project

The CSI AITR Event Management Dashboard is a responsive web application designed to help the CSI AITR Student Chapter manage and organize college events from one place.

The dashboard provides a simple interface to view events, manage registrations, track event progress, and check important event information.

## Features

### Dashboard

- Overview of total events
- Upcoming and completed event counts
- Registration overview
- Quick access to important sections

### Event Management

- View all events
- Add new events
- Edit existing events
- Delete events
- View complete event details
- Track event status
- Track registration progress

### Event Details

Each event contains important information such as:

- Event name
- Date and time
- Venue
- Event description
- Registration information
- Event status
- Registration count

The dashboard includes the MLH event **Prompt 2 Product** as a demo event.

### Registration Management

- View registrations by event
- Check registration details
- Search registrations
- Track the number of participants for an event

### Search and Filters

Search and filtering options help users quickly find events and registration information.

### Calendar

View events according to their scheduled dates.

### Analytics

View an overview of event and registration-related information.

### Local Storage

The project uses browser `localStorage` to store event and registration data. This allows data to remain available after refreshing the page without requiring a backend database.

## Demo Flow

1. Open the Dashboard.
2. Go to the Events section.
3. View the available events.
4. Select an event.
5. Open the Event Details page.
6. Check event information and registration progress.
7. Add, edit, or delete an event if required.
8. Open the Registrations section.
9. View and search registered participants.
10. Open the Calendar section to view scheduled events.
11. Open the Analytics section to view event and registration information.
